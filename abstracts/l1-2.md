Python — уроки 1–2
Конспект по пройденным темам. Учебный проект: планировщик задач, который в будущем станет Telegram-ботом. Сейчас пишем обычную программу в main.py и запускаем её в терминале.

1. Как работает программа
Алгоритм — последовательность действий для решения задачи. Программа — алгоритм, записанный на языке программирования.

Python выполняет команды из файла с расширением .py.
print("Привет, мир!")
- VS Code — редактор кода.
- Терминал — место, где вводим команды.
- Python — интерпретатор, который запускает код.
- Проект — папка с файлами программы.
Запуск из терминала в папке проекта:
python main.py
2. Переменные и типы данных
Переменная хранит значение под определённым именем. Оператор = присваивает значение.
name = "Аня"       # str — строка
age = 15           # int — целое число
hours = 1.5        # float — дробное число
is_done = False    # bool — True или False
Имена переменных пишем понятно, обычно в snake_case: task_name, task_count. Python различает заглавные и строчные буквы.

Узнать тип значения можно через type():
print(type(age))
3. Ввод и вывод
- print() выводит информацию в терминал.
- input() получает текст, введённый пользователем. Результат input() всегда имеет тип str.
- int() преобразует подходящую строку в целое число.
- f-строки позволяют вставлять значения переменных в текст.
name = input("Как тебя зовут? ")
tasks_count = int(input("Сколько у тебя дел сегодня? "))
print(f"Привет, {name}! У тебя {tasks_count} дел.")
Важно: "10" + "5" даёт "105", а 10 + 5 даёт 15.
4. Арифметика и сравнения
Оператор	Значение	Пример
+, -, *	Сложение, вычитание, умножение	3 + 2
/	Обычное деление	7 / 2 → 3.5
//	Целочисленное деление	7 // 2 → 3
%	Остаток от деления	7 % 2 → 1
**	Возведение в степень	2 ** 3 → 8
==, !=	Равно, не равно	age == 15
>, <, >=, <=	Сравнения	age >= 14


Для объединения условий есть and, or, not.
5. Условия
if, elif, else позволяют выполнить разные действия в зависимости от условия. Отступы в Python показывают, какие команды относятся к одному блоку.
count = int(input("Сколько дел запланировано? "))

if count == 0:
    print("Пока нет задач")
elif count == 1:
    print("Запланирована одна задача")
else:
    print("Запланировано несколько задач")
= — присваивание, == — проверка равенства.
6. Списки (list)
Список хранит несколько значений в определённом порядке. Список изменяемый: в него можно добавлять элементы, удалять их и заменять.
tasks = ["Сделать уроки", "Прочитать книгу", "Погулять"]

print(tasks[0])           # Первый элемент
print(tasks[-1])          # Последний элемент
print(len(tasks))         # Количество элементов

tasks.append("Убраться") # Добавить в конец
tasks[1] = "Прочитать 10 страниц"  # Изменить элемент
tasks.remove("Погулять") # Удалить по значению

print(tasks)
- Индексация начинается с нуля: tasks[0] — первый элемент.
- append() добавляет один элемент в конец списка.
- remove() удаляет первое совпадение по значению.
- pop(0) удаляет элемент по индексу и возвращает его.
- len(tasks) — количество элементов.
Попытка обратиться к несуществующему индексу вызывает IndexError.
7. Словари (dict)
Словарь хранит данные в виде пар ключ: значение. Словарь тоже изменяемый. В отличие от списка, значение получаем по ключу, а не по числовому индексу.
task = {
    "title": "Сделать уроки",
    "priority": "высокий",
    "done": False,
}

print(task["title"])     # Получение по ключу
task["done"] = True      # Изменение значения
task["day"] = "суббота" # Добавление новой пары

print(task)
Словарь помогает описать одну задачу, а список — хранить несколько задач:
tasks = [
    {"title": "Сделать уроки", "done": False},
    {"title": "Погулять", "done": True},
]

print(tasks[0]["title"]) # Название первой задачи
Сначала [0] выбирает первый словарь из списка, затем ["title"] — значение по ключу.
8. Git и GitHub — краткая памятка
Git хранит историю изменений проекта. GitHub позволяет хранить репозиторий удалённо. Коммит — зафиксированная версия изменений.

Клонируем репозиторий:
cd C:/
git clone {ссылка на проект}

Настройка автора в папке репозитория (подставить свои данные):
git config user.name "Name"
git config user.email "student@example.com"
После изменения main.py:
git status
git add main.py
git commit -m ""
git push
clone уже создаёт локальный Git-репозиторий и подключает удалённый origin: повторный git init не нужен.
