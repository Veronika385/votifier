Домашнее задание № 2 — первый прототип таск-планнера
Проект: планировщик дел на день (в будущем — Telegram-бот).

Цель: закрепить input(), print(), f-строки, списки (list) и словари (dict).

Ограничения: пишем всё в одном файле main.py, последовательно сверху вниз. Без циклов, функций, импортов и Telegram API. Используй только уже изученные конструкции. Не нужно реализовывать меню, которое работает бесконечно: пока это маленькая программа, выполняющая действия один раз за запуск.
Задание 1. Создай план на день
1. Спроси у пользователя его имя и на какой день он составляет план.
2. Попроси ввести названия трёх дел через три отдельных input().
3. Сохрани названия дел в один список tasks.
4. Выведи приветствие, название дня, число дел через len() и все три дела с номерами 1, 2, 3.
Пример работы программы:
Как тебя зовут? Аня
На какой день составляем план? Суббота
Первое дело: Сделать уроки
Второе дело: Погулять
Третье дело: Прочитать книгу

Аня, план на субботу готов!
Всего дел: 3
1. Сделать уроки
2. Погулять
3. Прочитать книгу
Подсказка: tasks[0], tasks[1], tasks[2] — первые три элемента списка.
Задание 2. Научись изменять план
Продолжай программу из задания 1.
1. Запроси название ещё одного дела и добавь его через append().
2. Спроси, какое дело пользователь хочет поставить вместо второго; замени элемент по индексу.
3. Удали первое дело с помощью pop(0).
4. Выведи обновлённый список и новое количество дел.
Подсказка: после удаления первого элемента остальные сдвигаются. Выведи tasks целиком, чтобы увидеть результат. Циклы пока не нужны.
Задание 3. Добавь подробности о задаче
Теперь опиши одно дело словарём task.
1. Спроси у пользователя название задачи и её приоритет (низкий, средний или высокий).
2. Создай словарь с ключами:
   - "title" — название из input();
   - "priority" — приоритет из input();
   - "done" — False (дело пока не выполнено).
3. Выведи значения словаря в читаемом виде через f-строку.
4. Измени значение "done" на True и выведи новый статус задачи.
Пример того, как могут выглядеть данные (не готовое решение):
{"title": "Сделать уроки", "priority": "высокий", "done": False}
Задание 4. ⭐ Дополнительно — список словарей
Соедини обе изученные структуры:
1. Создай два словаря — две разные задачи, у каждой есть "title" и "done".
2. Сложи словари в список tasks.
3. Выведи название первой задачи через tasks[0]["title"].
4. Измени статус второй задачи на True.
5. Выведи обе задачи и их статусы.
Это первая версия структуры данных для будущего Telegram-бота: одна задача — словарь, все задачи — список словарей.
